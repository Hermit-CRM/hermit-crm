Make it yours

Make it yours is how Hermit CRM changes: you describe a change in a sentence, and the AI agent you already use builds it in your data folder. The dashboards you make are pinned under Yours in the left navigation.

In the left navigation: Make it yours

Screenshot of the released version on made-up demo data. Select it to open it full size.

How a change happens

Open Make it yours in the sidebar, or the Adjust tab of the Ask · Adjust button on any page. Pick an idea or describe a change, then press Open in Claude Code, the button of the agent you use, or Copy prompt. Your agent follows a recipe that ships with Hermit, checks its own work with hermitcrm check, and makes one commit. Hermit picks the change up on the next page you open, with no restart.

A dashboard from one sentence

Lists, counts, bars and report sections as a page of your own at /d/<name>, pinned in the sidebar if you like. A dashboard only reads: it never changes a record, so it is safe to try. Every number opens the records behind it.

A new field

A score, a renewal date, a segment. One new entry in fields.toml, and the field shows on every company page, as a column you can sort and filter, and as a slot in your message drafts.

A routine that drafts follow-ups

Small jobs that run every morning: a brief of meetings, tasks and replies you owe, or one AI draft per quiet thread. A routine starts paused so you see first who it would pick, its drafts wait on Home for you to edit and send yourself, and Hermit never sends a message.

What you can change

  • Fields on companies and contacts.
  • Deal stages: their names, their order and which ones are closed.
  • Dashboards and page layouts.
  • The look: colours and fonts, in a theme.css of your own.
  • Message templates and routines.
  • Bulk changes to many records at once, after it asks first.
  • Bringing data in from another tool, and a feature Hermit cannot do yet.

Safe to try

Every change is a git commit. The list of Recent changes on the Make it yours page has an Undo button for each one. Your agent may only write the files the recipe lists, and records change only through the command line.

All features

Hermit CRM is a free, open-source CRM for founders, freelancers and anyone doing their own sales. It runs on your Mac or Linux computer and keeps every company, contact and conversation as a Markdown file in a git folder on your own disk. A local web app gives you a pipeline board, a calendar of next steps, message drafts and reports. AI tools such as Claude Code, Codex or Claude Desktop can read and update the pipeline through the files, a small CLI or the built-in MCP server. It is alpha software under the Apache License 2.0, with no warranty and no support.
