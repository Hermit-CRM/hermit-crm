BCC capture {{ status(state.bcc) }}

How it works: when you write to a prospect, put a tracking address in BCC (or forward the thread to it later). Hermit CRM reads that mailbox over IMAP, matches each message to a company by the other person's address or domain, and logs it as an interaction. Anything it cannot match waits in the review queue below. With Gmail, you+crm@gmail.com reaches your own inbox, so no second account is needed; a filter can file those messages out of the way.

Access

Two more ways into the same folder. Both start from a terminal, so this section is read-only.

From your phone

The app is bound to {{ access.host }}{% if not access.on_network %}, which only this machine can reach{% endif %}. Bind it to every interface and open the app on your phone over the same Wi-Fi:

{{ access.serve_command }}

Then open {{ access.lan_url }} on the phone. To make it permanent, set host = "0.0.0.0" in config.toml.

Hermit CRM has no password. Anyone who can reach that port can read and write your CRM, so use it on a network you trust, or a private one (Tailscale, WireGuard) rather than public Wi-Fi.

From an AI client (MCP)

Lets a desktop AI client on this machine — Claude Desktop, ChatGPT desktop, Cursor — read and write this CRM with no terminal: ask for your pipeline, what you owe a reply to, a brief before a meeting, and log the call afterwards. Seven read tools and three writes; the writes commit exactly as the web form does.

{{ access.mcp_command }}

It speaks on stdin and stdout, so you do not run it yourself: paste this into your client's MCP config and it starts it for you. That also means the client must run on this machine — a phone app cannot reach it. For the phone, use the section above.
